# Consumers

Worked setups for projects consuming this system. Each one is a real
configuration that was run, not a sketch.

- [astro.md](astro.md) — Astro 7 + Tailwind v4, which is what
  [we-are-archetype/website](https://github.com/we-are-archetype/website) runs.

The contract these all implement is [§9 of
DESIGN-SYSTEM.md](../../DESIGN-SYSTEM.md#9-consuming-this-system). If a setup
here disagrees with the spec, the spec is right and the setup is stale.
